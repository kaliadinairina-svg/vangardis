# Vangardis — лендинг адвокатського об'єднання

Навчальний кейс для портфоліо: односторінковий сайт для вигаданого адвокатського об'єднання, що спеціалізується на кримінальних справах.

**Жива версія:** _посилання з'явиться після публікації_

---

## ⚠️ Застереження

**Це вигаданий проєкт, створений винятково з навчальною метою.**

Адвокатське об'єднання «Vangardis» не існує. Усі номери телефонів, номери свідоцтв про право на заняття адвокатською діяльністю, адреси, імена адвокатів, описи справ і будь-які інші дані на сайті є **вигаданими**. Будь-які збіги з реальними особами, організаціями, справами чи контактними даними — **випадкові**.

Сайт не надає юридичних послуг і не є юридичною консультацією.

---

## Про задачу

Людина заходить на такий сайт у стресі — під час обшуку, після затримання близького, перед допитом. Тому головна ідея макета: не змушувати її розбиратися, яка саме послуга їй потрібна.

Перший екран починається з питання **«Що у вас сталося?»** — людина обирає свою ситуацію і одразу бачить свої права та що робити просто зараз. Кнопка дзвінка доступна з будь-якої точки сторінки.

## Структура сайту

1. Перший екран — вибір ситуації та права
2. Чим ми займаємося — 12 послуг
3. Від першого дзвінка до рішення — чотири кроки
4. Адвокати
5. Справи, які ми вели
6. Поширені запитання
7. Контакти і форма зворотного дзвінка

## Що зроблено

**Верстка**
- Семантична розмітка, `lang="uk"`
- Адаптив від 320px до 1440px, без горизонтального скролу
- Горизонтальні каруселі з прилипанням (`scroll-snap`) і керуванням стрілками
- Відео на першому екрані з постером і запасним форматом WebM

**Швидкість**
- Фотографії у WebP там, де це дає виграш (два файли лишені у JPEG — для них WebP виходив більшим)
- Відкладене завантаження зображень: перший екран тягне 7 картинок замість 22
- Відео у двох форматах, постер для першого кадру

**Доступність**
- Видимий фокус з клавіатури для всіх інтерактивних елементів
- Логічний порядок обходу по Tab
- `aria-label`, `aria-selected`, `alt` для всіх зображень
- Контраст тексту відповідає WCAG AA
- Повна підтримка `prefers-reduced-motion` — усі анімації вимикаються

**Анімація**
- Поява секцій і карток при скролі
- Проявлення заголовка з розмиття із запізнілим розгоранням кольору
- Підняття карток при наведенні
- Згасання країв каруселі там, де є продовження
- Одноразова підказка-поштовх, що каруселі гортаються
- Плавне розкриття питань у FAQ
- Кільце, що слідує за курсором (не приховує системний курсор)

## Дані та приватність

Сайт не використовує файли cookie, лічильники й аналітику. Єдиний зовнішній запит — шрифти з Google Fonts.

Форма зворотного дзвінка збирає лише ім'я та номер телефону. Галочка згоди не проставлена заздалегідь і посилається на [політику конфіденційності](privacy.html); без неї кнопка надсилання заблокована.

## Технології

Чистий HTML, CSS і JavaScript без фреймворків і без складання.
Шрифти — Cormorant SC і Manrope (Google Fonts).

## Як запустити локально

Сторінку краще відкривати через локальний сервер, а не подвійним кліком — інакше браузер може заблокувати відео:

```bash
python3 -m http.server 8000
```

Далі відкрити http://localhost:8000
